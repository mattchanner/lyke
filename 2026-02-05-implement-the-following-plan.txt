│ - FitInsightsAsync: Group PostProducts by product/size, aggregate            │
│ FitRatings, derive recommendation ("Runs Small"/"True to Size"/"Runs Large") │
│ - BodyProfileInsightsAsync (PRIVACY-CRITICAL):                               │
│   - Join Engagements with user BodyProfiles                                  │
│   - Bucket into height/weight ranges using same                              │
│ GetHeightRange/GetWeightRange from FeedService                               │
│   - k-anonymity: Suppress groups with < 5 users                              │
│   - Return MinimumGroupSize in response for transparency                     │
│   - Never expose individual body profile data                                │
